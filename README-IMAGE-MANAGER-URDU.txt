NEXURE&LAND WEBSITE IMAGE MANAGER — SETUP (Roman Urdu)

1) Supabase kholo aur SQL Editor > New query par jao.
2) Is folder ki site-images-setup.sql file kholo, poora code copy karke SQL Editor mein paste karo aur Run dabao.
3) Success aane ke baad project ki root files (index.html, app.js, styles.css, customer-dashboard.js, customer-dashboard.css, logo) GitHub par upload/replace karo.
4) Website par Ctrl + Shift + R karo aur admin account se sign in karo.
5) Admin Panel > Website Images kholo. Jis section ki picture badalni ho, Choose new picture dabao. JPG/PNG/WEBP, maximum 5 MB.

Available picture slots:
- Main hero banner
- Men’s collection card
- Casual collection card
- Formal collection card
- Our Story / editorial image

Images Supabase Storage mein upload hoti hain aur public website par show hoti hain. Sirf authorised admin upload kar sakta hai. Existing website design aur default pictures tab tak rehti hain jab tak tum apni picture upload nahi karte.
