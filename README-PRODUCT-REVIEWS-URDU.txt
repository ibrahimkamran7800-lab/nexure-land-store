NEXURE&LAND — Customer Product Reviews

Is update mein har product ke Quick View mein Customer Reviews ka section add kiya gaya hai. Customers stars (1–5) select karke apna review likh sakte hain. Reviews public taur par nazar aate hain. Review submit ya update karne ke liye customer ka sign-in hona aur us product ka order Delivered hona zaroori hai. Har customer har product par aik hi review rakh sakta hai; woh apna review update kar sakta hai.

ZAROORI SUPABASE SETUP:
1. Supabase Dashboard kholein.
2. SQL Editor mein jayein.
3. ZIP mein mojood product-reviews-supabase.sql file ka poora SQL copy karke New query mein paste karein.
4. Run par click karein.
5. Website ki updated files GitHub repository mein upload/replace karke commit karein.

Note: Database SQL run kiye baghair reviews load/submit nahi honge. Review policy sirf un products ke liye review allow karti hai jo signed-in customer ke apne Delivered order ke order_items mein maujood hon. Agar aapke Supabase order_items table mein product_id ka column name mukhtalif hai, SQL run karne se pehle us column name ko apne actual schema ke mutabiq adjust karna hoga.
